# My_Portfolio

Portfolio de développeur freelance au style « terminal », en français et en anglais.
Construit avec React 19, Vite, TypeScript et Tailwind CSS 4.

## Modifier le contenu

**Tout se trouve dans `src/content.ts`** : votre nom, votre e-mail, les textes FR/EN, les services, les projets et les technologies.
Les lignes à compléter sont marquées par `⚠`.

- **Captures d'écran des projets** : placez l'image dans `public/projects/`, puis indiquez `image: '/projects/nom.png'` dans le projet concerné.
- **Lien de démo** : remplissez `demo: 'https://...'`.

## Commandes

```bash
npm install      # une seule fois
npm run dev      # aperçu avec rechargement automatique (http://localhost:5173)
npm run build    # version finale dans dist/
```

## Mise en ligne (gratuite)

Sur [Vercel](https://vercel.com), importez le dépôt GitHub : Vite est détecté automatiquement.
Le contact se fait uniquement par e-mail : le bouton ouvre la messagerie du visiteur avec un modèle de demande de devis déjà rempli.
Un projet marqué `confidential: true` n'affiche ni capture ni lien vers le code.
